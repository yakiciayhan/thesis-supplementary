# ChatGPT Evaluation Outputs

This folder contains the ChatGPT evaluation outputs for all prompts used in the study. Each file corresponds to a single prompt submission in either English or Turkish, saved as a self-contained HTML file. To view a file, download it and open it in any web browser.

**File naming convention:** `[Prompt ID] [Language] [Run Type] ChatGPT ([Date]).html`

**Example:** `P01 EN ChatGPT (04_05_2026 17:05:46).html`
